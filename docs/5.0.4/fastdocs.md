# 5.0.4 FastDocs 路径处理修复

FastDocs 按 URL 路径规则处理文档名称，字面量 `+` 不再被解码为空格。
例如，`/docs/C++.md` 和 `/docs/C%2B%2B.md` 都读取 `C++.md`，而 `C%20%20.md` 读取 `C  .md`。

目录和面包屑链接按路径段进行 UTF-8 百分号编码，支持空格、中文、加号、`%`、`#`、`?` 等名称字符。
标题及面包屑仍显示原始名称，并保留 HTML 转义。路径只解码一次，再执行路径越界检查。
目录 iframe 的 `from_doc` 参数独立按查询参数编码。

非 JAR 部署使用资源 URL 对应的 URI 转换文件系统路径，因此部署目录含空格、中文或百分号时也能生成完整目录树。
JAR 部署继续使用原有 JAR 遍历方式，其目录链接使用相同的路径编码规则。

其余用法参见 [FastDocs 文档](../5.0.3/fastdocs.md)。
